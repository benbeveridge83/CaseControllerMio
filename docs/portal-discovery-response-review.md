# Client discovery originals and attorney response assembly

Clients open Discovery, choose an assigned set, and use **Download original requests** to read the served PDF or Word document. The source comes from that set's linked matter document, with a short-lived download URL. Existing released sets retain their verified original-document reference.

Staff open the matter's Discovery tab or Client Portal tab and choose **Review & assemble responses** on a released set.

1. Select the applicable filing-date regime, discovery control level, drafting threshold and case facts before running AI analysis. This uses the existing Discovery Objections engine, curated sources and the staff member's confirmed saved personal examples.
2. Run analysis for the set or an individual request. AI objection and privilege candidates start unselected. Edit the language and select only what should be included.
3. Open a request to see the untouched client answer and private client questions. Choose **Adopt client answer** or **Write or modify attorney response**. The attorney field is separate from the client's original words.
4. Review the response and selected objections, check the approval box, and save. **Save all review changes** saves pending reviews one at a time with acknowledged version checks.
5. Use **Assemble reviewed Word responses** once every request is approved and saved. The document contains the original request numbers, chosen responses and selected objections/privileges. It excludes private client comments, guidance, analysis explanations and unselected candidates.
6. **Download working draft with placeholders** is available earlier. Every unreviewed request remains present with an attorney-review placeholder; client answers are never silently adopted.
7. Drafts are saved privately with the discovery set and can be downloaded again. They are snapshots: the history flags subsequent changes to client answers, requests, uploads or attorney review.

The output uses the existing Word exporter. It is labeled as an attorney-review draft and leaves the preferred case caption, signature, service certificate and any required verification to the attorney's response form. It does not claim to apply a custom Drafting Studio template, file or serve documents, send client messages, or treat uploads to the firm as service on opposing counsel.

The workspace refreshes saved responses while idle. A refresh cannot overwrite edits begun while it was loading. Unsaved attorney review changes are backed up per staff account/matter/set on the device. On a conflict, **Compare latest saved responses** preserves those edits and loads the newer record for comparison. Adoption or an explicit keep-my-changes action resets approval so the revised review must be approved again.

Server review saves lock the answer row, check both client and attorney-review versions, and never rewrite client-answer fields. An identical retry after a lost acknowledgment returns the saved review. Original downloads check the assigned set and the authoritative matter/document reference. Review tables, draft storage and privileged RPCs are unavailable directly to anonymous and client roles.
